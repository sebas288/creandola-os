# Caso Laura — seguimiento de procesos legales

Primer caso real/semi-real para validar el Context Engine de Creándola fuera del piloto interno.

## Camino rápido

1. Validar con Laura las etapas reales de sus procesos.
2. Elegir 3-5 procesos anonimizados.
3. Cargar esos procesos en una herramienta privada autorizada.
4. Generar el primer reporte semanal.

## Archivos

| Archivo | Uso |
|---|---|
| `context-engine.md` | Mapa de entidades, relaciones, decisiones y tareas del caso. |
| `diagnostico-horizontal.md` | Diagnóstico aplicado al despacho y horizontales prioritarias. |
| `crm-horizontal.csv` | Estructura inicial de seguimiento con filas anonimizadas. |
| `reporte-mensual.md` | Reporte inicial para validar valor operativo. |
| `propuesta-horizontal.md` | Propuesta de piloto manual para Laura. |

## Regla de privacidad

No guardar nombres reales de clientes finales, cédulas, expedientes, juzgados, valores, documentos jurídicos ni datos de contacto en este repo. Los datos reales van en una herramienta privada autorizada por Laura.
